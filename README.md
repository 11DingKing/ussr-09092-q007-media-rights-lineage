# 首发影像授权谱系

这里保存首发报道影像的权利字段和派生关系约定。原图、裁切图、压缩图与字幕版都要能追溯到源文件；授权包含渠道、地域、期限和撤回信息，原始素材摘要与决定记录只追加保存。

`app/models` 预留素材和授权对象，`app/lineage` 负责派生图谱，`app/jobs` 负责缩略图队列和恢复，`app/persistence` 接入 SQLite，`web` 目录供编辑与法务页面使用。示例素材是虚构摘要，不包含真实照片。项目采用 Ruby 3.3 的 Rails 目录习惯，当前可用标准 Ruby 检查。

执行 `ruby -Itest test/models_test.rb` 检查骨架。
